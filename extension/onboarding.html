🔍 企查查速查助手

自动登录 · 单窗口标签管理 · Mac / Windows 通用（Chrome、Edge 均可）

第 1 步安装扩展（约 1 分钟，仅需一次）

  1. 把收到的压缩包解压，得到 extension 文件夹（整个文件夹要保留在电脑上，建议放到文档目录，解压后不要删除）。
  2. 打开 Chrome，在地址栏输入 chrome://extensions 后回车，进入「扩展程序」管理页。
    用 Edge 的话输入 edge://extensions，其余步骤相同。
  3. 打开页面上的 「开发者模式」 开关——Chrome 在右上角，Edge 在左侧栏。
  4. 点击 「加载已解压的扩展程序」（Mac：Load Unpacked），在弹出的文件夹选择框里选中刚才的 extension 文件夹，点「选择」。
  5. 固定到工具栏：点地址栏右侧的拼图图标 🧩，找到「企查查速查助手」，点后面的图钉 📌。

第 2 步首次登录（只输入一次账号密码）

  1. 点击浏览器工具栏的 企查查速查助手 图标，会自动打开企查查查询页。
  2. 如果跳到登录页，会自动弹出「首次登录」框：输入你的 IMS 账号和密码，点「保存并登录」。
  3. 完成。之后每次打开都会自动登录，不再需要重复输入；会话过期时也会自动续期。

🛡️ 关于权限：不需要开启任何系统权限

✅ 需要做的

只有上面第 1 步的「开发者模式 + 加载已解压的扩展程序」。这是 Chrome 对非商店扩展的唯一要求，开关在扩展管理页里，不是系统设置。

❌ 不需要动的

不需要辅助功能、不需要屏幕录制、不需要「自动化」、不需要终端/开发者工具权限。如果任何软件让你去「系统设置 → 隐私与安全性」里授权，那不是本工具。

🔒 密码安全

你的账号密码只保存在自己电脑的浏览器里（扩展本地存储），不上传任何服务器、不随浏览器账号同步、 也不存在于代码和压缩包中。换电脑或换同事使用时，各自输入一次各自的 IMS 账号密码即可。

❓ 常见问题

点击企业后应该在同一个窗口里开新标签，为什么有时还是弹出新窗口？

请始终通过工具栏扩展图标打开查询页（可到 chrome://extensions/shortcuts 给它设置快捷键，如 Alt+Q）。 扩展会自动把企查查的弹窗改写成同一窗口的新标签。如果从旧的书签/桌面快捷方式打开，行为可能不受扩展控制。

密码输错了 / 想更换账号？

点下方「打开账号设置」修改，或在工具栏图标上右键 → 选项。连续登录失败 3 次时，扩展会自动停用已存密码并要求重新输入。

公司电脑的 Chrome 提示「无法加载扩展 / 已被管理员停用」？

个别企业管控版 Chrome 禁止加载未上架扩展，需要联系 IT 在管理策略中放行，或改用未受管控的 Chrome/Edge 个人版。
